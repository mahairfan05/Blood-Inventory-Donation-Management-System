2.Product Perspective:
The Blood Donation Management System is a database-supported application for managing blood donation and blood bank operations. It will maintain structured records of donors, donations, blood units, blood groups, hospitals or branches, camps or locations, patients, requests, and issued blood units. Authorized users will access the system through a graphical user interface, while stored information will be maintained in a centralized database. 


3. Tech Stack-
   Frontend: react.js and Tailwind.css
   Backend: Node.js and Express.js
   Database: Supabase
   Location: Google Maps API
   Notifications: Firebase cloud messaging
   Authentication: Supabase
   Deployment: Vercel
